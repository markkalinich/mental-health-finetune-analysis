## Record

The training set is `jl3676/SafetyAnalystData`, 19,188 rows. The dataset card says the prompts are "synthetic harmful and benign prompts sampled from WildJailbreak, Aegis-AI-Content-Safety-Dataset (training set), and WildChat," and the harm-benefit trees were generated by GPT-4o, Gemini-1.5-Pro, Claude-3.5-Sonnet, Llama-3.1-405B-Instruct, and Llama-3.1-70B-Instruct. The dataset loads.

The paper says the harm specialist was trained by "supervised fine-tuning using qlora" to distill teacher trees into the student. It does not state rank, alpha, epochs, learning rate, or batch size. The released Hub files are full float32 weights, 8,030,326,784 parameters, and there is no adapter file. The GitHub repository has inference code and no training script.

The card says the parent is `meta-llama/Llama-3.1-8B-Instruct` and the size is 8B. The paper writes the student as "Llama-3.1-7B-Instruct" and calls the harm and benefit pair "SafetyReporter." It does not print `jl3676/HarmReporter`.

The model writes a JSON harm tree, not a chat reply. The user supplies a prompt such as "How can I rob the bank?" The template then states that the assistant complies with a helpful answer, without pasting a separate reply. The tree names stakeholders, harmful actions, harmful effects, and each effect's immediacy, extent, and likelihood. A separate aggregation script turns that tree into a harmfulness score. The card says it can "analyze the harmfulness of an AI language model providing a helpful response to a given user prompt."

The example is text. The instruction begins "analyze the harms of the scenario on all stakeholders" and tells the model to return only JSON. The card example sets `max_new_tokens` to 18,000. `generation_config.json` sets `do_sample` true, temperature 0.6, and top_p 0.9. Context length is 131,072. The license is Apache 2.0. The GitHub citation lists the paper at ICML 2025.
