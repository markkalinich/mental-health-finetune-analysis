## Record

The configured training lineage is 83,787 rows: 79,288 first-stage rows plus 4,499 supplemental rows. The card says "This is continued adaptation, not a fresh 83,787-record training run." Counts from the card and `training_dataset_summary.json`: Aegis V2 25,569, OR-Bench 20,062, Chinese Do-Not-Answer 2,724, AdvBench 509, HarmBench 391, JBB-Behaviors 200, corrected Qwen3.5-4B synthetic data 29,833, and a five-category AI synthetic supplement 4,499. Labels are 49,802 SAFE and 33,985 UNSAFE. A separate 500-row validation set is not in the training total.

Aegis V2 is `nvidia/Aegis-AI-Content-Safety-Dataset-2.0`. It loads. The dataset card says 33,416 annotated interactions. Provenance is mixed: "we use the HuggingFace version of human preference data about harmlessness from Anthropic HH-RLHF. We extract only the prompts, and elicit responses from Mistral-7B-v0.1." Language is English. OR-Bench is `bench-llm/or-bench`. It loads. The card says "We automate the process of producing seemingly toxic prompts," so the provenance is synthetic. Language is English. The Hub copy has 80,359 rows in the 80k config; this model used 20,062. Chinese Do-Not-Answer matches `walledai/CDNA` (2,726 rows, language zh, loads). The model used 2,724. The dataset card says "Authors construct a Chinese LLM safety evaluation by translating and localizing" the English Do-Not-Answer set, so the provenance is human. The English Hub set `LibrAI/do-not-answer` has 939 rows and is not this training slice. AdvBench is `walledai/AdvBench` (gated, does not load anonymously; metadata says 520 examples; this model used 509). HarmBench is `walledai/HarmBench` (gated, does not load anonymously; standard 200, contextual 100, and copyright 100; this model used 391). Neither gated card states whether the rows are human or synthetic. JBB-Behaviors is `JailbreakBench/JBB-Behaviors`. It loads. The behaviors config has 200 rows, which matches the training count. The card says the behaviors are "both original and sourced from prior work" and does not say human or synthetic. The two synthetic sources are not on the Hub. The summary file says the Qwen rows are "generated, reviewed and corrected," so that source is mixed, and the supplement is "AI-generated," so that source is synthetic. The five category names are not stated. Raw training text is not in the model repository.

The training objective is classification. The card says "Only text-input safety classification was trained and evaluated." The update is LoRA. The card says the repository "preserves the original LoRA tensors in `adapter/`." `adapter_config.json` has `peft_type` LORA, rank 16, alpha 32, dropout 0.05, and `task_type` CAUSAL_LM. The published weights are a merged BF16 model. The card says "Do not apply the adapter on top of this repository's already merged weights." Epochs, steps, learning rate, and batch size are not stated. The calibration file's model name contains the words "low-lr" and does not give a number. Whether the base was quantized during training is not stated. The card says historical benchmark numbers use "NF4 upstream base plus the original unmerged adapter," which is the evaluation load, not a training sentence.

The parent is `Qwen/Qwen3.5-4B`, revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`. The card, `adapter_config.json`, and `danger_intent_config.json` agree. The Hub safetensors count is 4,539,265,536 parameters. The card says English and Chinese are in the task and training data, and that the expanded comparison is English only. The license on the new fine-tune, including the adapter, is CC-BY-NC-4.0. The base and `predict.py` stay Apache-2.0.

This is a classifier. The card says "It is a research classifier, not a general-purpose assistant." The input is one user text. The example is `python predict.py --model . --text "How do I protect my email account?"`. The fixed instruction, from `danger_intent_config.json`, is "判断以下用户请求是否包含危险意图或明显违反安全政策的意图。只输出 SAFE 或 UNSAFE，不要解释。" That asks for a binary SAFE or UNSAFE label and no explanation. The scorer also returns a risk score, a raw margin, a threshold, and a truncation flag as one JSON object. The card says "Output includes the binary prediction, raw margin, risk score, threshold and truncation indicator." The card does not name a harm-category list. It claims the model classifies a user input as SAFE or UNSAFE.

Serving is text only. The card says "Only text-input safety classification was trained and evaluated; no image/video safety claim is made." The classification context is 1,024 tokens. `generation_config.json` does not set temperature, top_p, top_k, or do_sample. The chat template is present and is the upstream Qwen template. `predict.py` does not use it. It builds `<|im_start|>user`, the instruction, the user text, then `<|im_start|>assistant`, and scores the tokens SAFE and UNSAFE.

Calibration on 450 XSTest margin rows, at threshold 0.3504582245139618, has accuracy 0.9177777777777778. The card says XSTest is not a new blind holdout. The expanded comparison file scores an ensemble. It does not give a standalone full-suite number for this checkpoint. No paper and no GitHub training repository name this model. The arXiv HTML for 2607.12792 evaluates other models and does not print this repository id.
