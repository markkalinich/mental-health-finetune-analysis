## Record

The training set is ReasoningShield/ReasoningShield-Dataset, 7,000 (Query, CoT) pairs. The dataset card splits that into 4,358 agreed-on samples for supervised fine-tuning and 2,642 hard-negative samples for direct preference optimization. The Hub dataset page loads. The dataset card says the pairs are "human-AI annotated," and the reasoning traces were generated by other models, so the provenance is mixed. Language on the model card and the dataset card is English.

The paper names two losses for this checkpoint. Stage 1 is "Supervised Fine-Tuning (SFT)." Stage 2 is "Direct Preference Optimization (DPO)." Both stages update all weights: "full-parameter fine-tuning" and "full-parameter DPO training," in bf16, batch size 2. Stage 1 runs 3 epochs at learning rate \(1\times 10^{-5}\). Stage 2 runs 2 epochs at learning rate \(2.0\times 10^{-6}\). No source states a LoRA rank, a step count, or that an adapter was merged. The repository ships two safetensors shards and no `adapter_config.json`.

The card's `base_model` field is `meta-llama/Llama-3.2-3B-Instruct`. The paper says "We select Llama-3.2-1B and Llama-3.2-3B (Meta, 2024a) as the base models," and does not print "Instruct." The authors name this checkpoint ReasoningShield-3B. The GitHub README links `https://huggingface.co/ReasoningShield/ReasoningShield-3B`. The paper does not print that repository id.

The card describes a safety moderation model that assigns a risk level to a reasoning trace. That is a classifier, not a conversation partner. Nothing on the card claims therapy, counseling, or emotional support. The card has no sentence that forbids or disclaims therapy or medical use. The card reports a chain-of-thought moderation F1 "over 91%" on open-source traces; the 3B row is 91.8 average on open-source traces and 81.4 on commercial traces. License is Apache 2.0.

The usage example sends a text query and a text thought, with no image or audio. `tokenizer_config.json` contains a Llama 3 chat template. The system prompt in `reasoningshield_prompt.txt` tells the model it is a risk auditor and to end with `"Judgment": [0/0.5/1]`. `generation_config.json` sets `do_sample` true, temperature 0.6, and top_p 0.9. `config.json` sets `max_position_embeddings` to 131072. The card's example uses `max_new_tokens` 1024.
