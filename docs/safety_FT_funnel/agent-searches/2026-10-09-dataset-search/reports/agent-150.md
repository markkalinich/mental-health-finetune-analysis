# Agent 150 dataset search

## nullHawk/Param-1-2.9B-Instruct-Refusal-Abliterated

No training corpus is named for this checkpoint. The cached card and the live card match. They say the refusal direction was removed from layers 10–20 of bharatgenai/Param-1-2.9B-Instruct. The repository files are the model, tokenizer, and modeling code, with no training script. The same author describes this checkpoint and says it was made without fine-tuning. That write-up names mlabonne/harmful_behaviors and mlabonne/harmless_alpaca as the prompts used to compute the refusal direction. Both Hub dataset pages load. The cited paper, arXiv 2406.11717, studies other chat models and does not mention this repository.

## NullpoLab/Agents-A1-4B-Heretic-ARA-Refusals0

No training corpus is named for this checkpoint. The cached card and the live card match. This is a weight edit of InternScience/Agents-A1-4B made with Heretic v1.2.0 Arbitrary-Rank Ablation. The repository has an English README and no training script. The card uses mlabonne/harmful_behaviors and mlabonne/harmless_alpaca as the 100-prompt sets for refusal rate (0/100) and KL divergence (0.0116). Both dataset pages load. Heretic's default config names those same datasets as the prompts for the weight edit, and that file does not mention this repository.
