# Safety suicidal-ideation run, 14 October 2026

`bash_scripts/run_safety_si.sh` served the nine safety fine-tunes in `revision_3_experiments/safety_native/cohort.py` (`USABLE`) and their eight instruction parents. Two fine-tunes share `meta-llama/Llama-3.1-8B-Instruct`, so that parent is listed once. The run started at 21:33 ET and the driver finished all 17 the same evening. The stamp directory is `results/safety-si/rtx-20261014_213319/`. Per-model files are `results/safety-si/<org>__<name>/{predictions.jsonl,summary.json}`.

Each model saw 450 synthetic sentences (`data/inputs/finalized_input_data/SI_finalized_sentences.csv`) and 500 C-SSRS users (`/home/mkalinich/local_benchmarks/reddit_cssrs/prepared/standard_user_level.csv`). A fine-tune got its own card prompt and its own label parser (`revision_3_experiments/safety_native/prompts.py`, `parse.py`). A parent got `data/prompts/suicide_ideation_yesno_v1.txt` on the synthetic set and `data/prompts/cssrs_severity_v1.txt` on C-SSRS. Both are then scored as yes or no in `revision_3_experiments/safety_native/score.py`. An unparsed reply is not a yes and is not counted correct. The yes/no field in `summary.json` is `n_correct` over `n`. There were no API errors.

Qwen parents, Shield Qwen, and tinysafe were sent `enable_thinking` false. FlexGuard was sent `enable_thinking` true because its card requires the think block before the category and the risk score. Shield `max_tokens` is 4 because the card example is `max_new_tokens` 4. The other caps are on the specs in `cohort.py`: aims 512, FlexGuard 2048, tinysafe 128, parents 256.

To run it again, with the GPU free:

```bash
bash bash_scripts/run_safety_si.sh
```

A model whose summary already has 450 synthetic rows, 500 C-SSRS rows, and zero API errors is skipped.
