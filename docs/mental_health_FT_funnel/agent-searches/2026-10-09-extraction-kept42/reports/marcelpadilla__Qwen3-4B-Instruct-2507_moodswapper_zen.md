No batch size. No sentence says the base was quantized during training. The uploaded weights are two BF16 shards, 4,022,468,096 parameters, and there is no adapter file. The parent is `Qwen/Qwen3-4B-Instruct-2507` on the card and in `moodswapper.json`.

The card says "Only the emotional tone changed." It does not offer therapy, counseling, or emotional support. The use claim is Absent. There is no warning. It is still the instruct model answering a person, so the output type is Chatbot. License is Apache-2.0. No paper names this repository. The report's test is 24 prompts, calm score 1.97 to 2.79 of 3, with the base model as the judge.
