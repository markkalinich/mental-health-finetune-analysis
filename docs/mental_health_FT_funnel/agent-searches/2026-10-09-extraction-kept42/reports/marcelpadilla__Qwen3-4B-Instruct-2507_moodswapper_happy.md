## Record

The training rows were written by the base model. moodswapper.json says `"data_source": "generated by Qwen/Qwen3-4B-Instruct-2507"` and `"n_examples": 1936` (1,900 mood answers and 36 refusals). They are stored as `dataset.jsonl` in this repository, not as a separate Hub dataset, so that file is not a dataset the Hub dataset viewer loads. The teacher line is "Answer in a happy way, but still give me the actual answer." The kept answers are English.

The training script says "Train a LoRA on the dataset, then fold it into the weights" and "The prompt is masked out of the loss." That is supervised training on the answer tokens. The README says "A small LoRA is trained on those and folded into the weights." This run's moodswapper.json records rank 16, alpha 32, learning rate 0.0002, 3 epochs, and 363 steps. The script's per-device batch is 4 and gradient accumulation is 4. Those two numbers times the 1,936 examples and 3 epochs equal 363 steps. The json stage list ends with "Merging and saving." Whether the base was quantized while training is not stated. The script turns on bf16 when the loaded model is bfloat16.

The card and moodswapper.json both name the parent Qwen/Qwen3-4B-Instruct-2507. This repository's weight count is 4,022,468,096 parameters. The parent card says "Number of Parameters: 4.0B."

The card says the model is Qwen3-4B-Instruct-2507 "with happiness in its weights" and "Only the emotional tone changed." The README says "The model still answers the request, correctly and at about the same length, just in that mood." That is a chatbot. The claim is a mood change, not therapy or a support conversation, so the use claim is weak. No sentence forbids therapy or medical use. On 24 held-out prompts, mean mood score is 2.63 against 1.76 for the base. Final training loss is 0.357.

The parent quickstart runs on text: `prompt = "Give me a short introduction to large language model."` generation_config.json sets temperature 0.7, top_p 0.8, top_k 20, and do_sample true. Context length is 262,144 tokens. The chat template has no fixed system line. License is Apache-2.0, as the base model. There is no paper. The project page is a work-in-progress note, not a preprint. Inventory methods is empty; the files name LoRA.
