## Record

The card says this checkpoint was supervised-fine-tuned on SQPsychConv (Gemma): "This checkpoint is **Qwen2.5-7B-Instruct** supervised-fine-tuned on **SQPsychConv (Gemma)**, the synthetic corpus generated by `google/gemma-3-27b-it` from real, de-identified structured client profiles and psychological questionnaires (BDI, HAM-D)." The same card says "The instruction-formatted split used for training is `AIMH/SQPsychConv_gemma_finetune`." Both Hub datasets load. The dialogue card lists 1,837 train rows and 253 test rows (2,090; the project page lists 2.09k). The finetune card lists 28,434 train rows and 3,931 test rows (32,365; the project page lists 32.4k). The dataset cards do not name a language. The conversations are synthetic. The dialogues were generated by `google/gemma-3-27b-it` and conditioned on de-identified profiles and BDI and HAM-D scores from Kircher et al. (2019).

The objective is supervised fine-tuning. The card says "supervised-fine-tuned." The card does not say whether training updated every weight, a LoRA adapter, or QLoRA. The repository has one `model.safetensors` file and no `adapter_config.json`. Rank, alpha, whether an adapter was merged, epochs, steps, learning rate, and batch size are not stated for this checkpoint. The linked script `src/finetune.py` hardcodes `base_model = "meta-llama/Meta-Llama-3-8B-Instruct"`, uses `SFTTrainer` for 5 epochs at learning rate `2e-5` and batch size 2, and does not name this repository. The paper says "we fine-tune Llama3-8B-Instruct" and "We use the same hyperparameters for finetuning SQPsychLLM" (5 epochs, learning rate 2e-4, full BF16, copied from the Psych8k baseline). That paper does not print `AIMH/SQPsych-8b-gemma-Qwen`.

The Hub record reports 7,615,616,512 parameters. The paper's fine-tunes are Llama-3-8B-Instruct and do not name this checkpoint.

The card presents a chat model that roleplays a therapist: "`SQPsych-8b-gemma-Qwen` is a chat model fine-tuned to **roleplay a therapist** in synthetic, Cognitive Behavioral Therapy (CBT)-informed counseling conversations." That is a chatbot, and the therapy claim is strong. The warning is an explicit prohibition: "This model must **not** be used to: provide therapy, diagnosis, or any clinical decision to real people." The paper's CounselingBench and CBT-Bench tables are for the Llama SQPsychLLM models.
