## Record

The card says this checkpoint was supervised-fine-tuned on SQPsychConv (Gemma): "This checkpoint is **Llama-3-8B-Instruct** supervised-fine-tuned on **SQPsychConv (Gemma)**, the synthetic corpus generated by `google/gemma-3-27b-it` from real, de-identified structured client profiles and psychological questionnaires (BDI, HAM-D)." It also says "The instruction-formatted split used for training is `AIMH/SQPsychConv_gemma_finetune`." Both Hub datasets load. The dialogue card lists 1,837 train rows and 253 test rows (2,090). The finetune card lists 28,434 train rows and 3,931 test rows (32,365). Neither dataset card states a language. The conversations are synthetic.

The objective is supervised fine-tuning. The paper says the SQPsychLLM models, which it defines as Llama3-8B-Instruct fine-tuned on each synthetic corpus, use "a full BF16 fine-tuning" and "the same hyperparameters" as the Psych8k baseline: "5 epochs, learning rate 2e-4." The released script `src/finetune.py` loads `meta-llama/Meta-Llama-3-8B-Instruct` in bfloat16 with `SFTTrainer`, default 5 epochs, `per_device_train_batch_size=2`, and `gradient_accumulation_steps=16`. That script sets `learning_rate=2e-5`, not 2e-4. It does not use LoRA or a quantized base. Rank, alpha, step count, and whether an adapter was merged are not stated. The learning rate is not recorded as one number because the paper and the script disagree.

The card names the parent as `meta-llama/Meta-Llama-3-8B-Instruct`. The paper says "we fine-tune Llama3-8B-Instruct." The script sets `base_model = "meta-llama/Meta-Llama-3-8B-Instruct"`. `config.json` is `LlamaForCausalLM`. The Hub record reports 8,030,261,248 float32 parameters. The project page lists this exact id as an 8B model trained on SQPsychConv (Gemma). The paper writes "SQPsychLLM gemma" and does not print `AIMH/SQPsychLLM-8b-gemma`. The GitHub README does print that id.

The card presents a chat model that roleplays a therapist. That is a chatbot, and the therapy claim is strong. The warning is an explicit prohibition: "This model must **not** be used to: provide therapy, diagnosis, or any clinical decision to real people." Language is English. The YAML license is llama3. The prose says "Llama 3 Community License."

Table 3's questionnaire-conditioned row for SQPsychLLM gemma is CounselingBench zero-shot R 0.49 and F1 0.48, zero-shot CoT R 0.58 and S 0.58, CBT-CD R 0.55 and F1 0.35, CBT-PC R 0.80 and F1 0.71, and CBT-FC R 0.58 and F1 0.35. The paper says experts preferred SQPsychLLM gemma over CAMEL, Psych8k, and Llama-3-8B-Instruct.

The usage example is text only. The example system string is "You are an empathetic therapist conducting a CBT-informed session." `generation_config.json` sets `do_sample` true, temperature 0.6, top_p 0.9, and max_length 4096. `config.json` sets `max_position_embeddings` to 8192. The repository has no chat template file. The example still calls `apply_chat_template`.

The inventory row matches the card on supervised fine-tuning, on `AIMH/SQPsychConv_gemma`, and on `meta-llama/Meta-Llama-3-8B-Instruct`. The card also names `AIMH/SQPsychConv_gemma_finetune` as the split used for training.
