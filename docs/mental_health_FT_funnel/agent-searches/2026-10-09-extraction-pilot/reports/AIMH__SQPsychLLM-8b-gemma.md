## Record

The training conversations are synthetic. The card says: "This checkpoint is Llama-3-8B-Instruct supervised-fine-tuned on SQPsychConv (Gemma), the synthetic corpus generated by google/gemma-3-27b-it from real, de-identified structured client profiles and psychological questionnaires (BDI, HAM-D)." It names `AIMH/SQPsychConv_gemma` and says: "The instruction-formatted split used for training is AIMH/SQPsychConv_gemma_finetune." The conversation dataset has 2,090 rows (1,837 train, 253 test). The paper says the authors generated 2,090 conversations per model and counts 71,000 utterances for the Gemma corpus. The fine-tune dataset has 32,365 rows (28,434 train, 3,931 test). Both are public, ungated, and the Hub viewer returns rows. A train row's instruction is "You are a state-licensed therapist trained in Cognitive Behavioral Therapy (CBT), please answer the patient." The dataset cards have no prose, only YAML. The model card says the language is English. The dataset cards do not state a language.

The objective is supervised fine-tuning. The card says this checkpoint was "supervised-fine-tuned." The paper says the authors fine-tune Llama3-8B-Instruct on each portion of the synthetic dataset, and then: "we perform a full BF16 fine-tuning of Llama3-8B-Instruct on Psych8k, using the same hyperparameters as CAMEL (5 epochs, learning rate 2e-4). We use the same hyperparameters for finetuning SQPsychLLM." That states 5 epochs, learning rate 0.0002, and full bfloat16 updates for SQPsychLLM. The published script `src/finetune.py` loads `meta-llama/Meta-Llama-3-8B-Instruct` in bfloat16 and trains it with TRL `SFTTrainer`, with no LoRA configuration. Its defaults are 5 epochs, learning rate 2e-5, per-device batch size 2, and gradient accumulation 16. The script does not name this repository, and its learning rate does not match the paper, so the batch size is not recorded as this checkpoint's batch size. No source states a LoRA rank, a LoRA alpha, or that an adapter was merged. The repository has no adapter file. The script builds each training string from `input` plus `output` and does not prepend the dataset's instruction field.

The parent is `meta-llama/Meta-Llama-3-8B-Instruct`. The card says "Finetuned from model: meta-llama/Meta-Llama-3-8B-Instruct." The paper says "we fine-tune Llama3-8B-Instruct." The training script sets `base_model = "meta-llama/Meta-Llama-3-8B-Instruct"`. Those agree with the card. The word "gemma" in the repository name is the generator of the conversations, `google/gemma-3-27b-it`, not the parent. The project page lists this repository as an 8B model trained on SQPsychConv (Gemma). The Hub weight-file count is 8,030,261,248 parameters. `config.json` is a `LlamaForCausalLM` with vocabulary size 128,256 and `max_position_embeddings` 8192. The paper names the checkpoint "SQPsychLLM gemma" and does not print `AIMH/SQPsychLLM-8b-gemma`. The project page and the GitHub README do.

The card presents a chatbot. It says: "SQPsychLLM-8b-gemma is a chat model fine-tuned to roleplay a therapist in synthetic, Cognitive Behavioral Therapy (CBT)-informed counseling conversations." That is a strong therapy-use claim. The warning is an explicit prohibition. The card says: "This model must not be used to: provide therapy, diagnosis, or any clinical decision to real people." It also says the model is for research use only and is not a substitute for professional care. The card license is `llama3`, and the prose says Llama 3 Community License. The paper reports CounselingBench, CBT Bench, an LLM panel, and a blinded expert preference comparison, and says experts preferred SQPsychLLM gemma over CAMEL, Psych8k, and Llama-3-8B-Instruct.

The repository has no chat template. `tokenizer_config.json`, `tokenizer.json`, and `chat_template.jinja` return 404, and the file list has no tokenizer. `generation_config.json` sets `do_sample` true, temperature 0.6, top_p 0.9, and `max_length` 4096. The card example uses temperature 0.7, `do_sample` true, and `max_new_tokens` 512, with the system text "You are an empathetic therapist conducting a CBT-informed session." That sentence is the card's example. It is not stored in the repository. The inventory method `sft` and parent `meta-llama/Meta-Llama-3-8B-Instruct` match the card. The inventory dataset matches the card YAML, and the card also names `AIMH/SQPsychConv_gemma_finetune` as the split used for training.
