## Record

The training mix is two Hub datasets, and the card's pie chart does not match the notebook log. CounselChat, `nbertagnolli/counsel-chat`, has 2,775 rows and loads. The dataset card says, "The text was written by licensed counselors in the United States and annonymous individuals," and "The dataset was scraped on 20220401 from counselchat.com." Language on that card is English. The notebook printed "✅ CounselChat:   2,775 → 2,598 samples" and put those 2,598 into the mix. PHR, `vibhorag101/phr_mental_therapy_dataset`, has 99,086 rows and loads. Its card says, "The data is generated synthetically using gpt3.5-turbo," and that it is a cleaned copy of `jerryjalapeno/nart-100k-synthetic` in Llama-2 chat format. The notebook printed "✅ PHR Therapy:   99,086 → 25,838 samples." It then capped the shuffled mix at 15,000 rows (14,250 train, 750 validation) and trained on the first half of that train split: 7,125 rows, with 375 validation rows. The card instead says 2,598 CounselChat plus 4,527 PHR, totaling 7,125, with a 6,768/357 split, and it calls the PHR text "Empathetic dialogue in Mistral Instruct format." The printed PHR sample is still the Llama-2 `<<SYS>>` text. A later notebook cell formatted a set it labels `blended_skill_talk` (4,819 conversations, 26,568 pairs). That cell was not the trainer input. The load call for that set is not in the saved notebook. A final summary cell that did not run names "Amod MHCC + CounselChat + Empathetic Dialogues."

The method is supervised fine-tuning with QLoRA, for 1 epoch, and the adapter was merged before upload. The card says "SFTTrainer · 1 Epoch" and "QLoRA (4-bit NF4 Quantization)." The notebook's training cell uses `SFTTrainer` with `num_train_epochs=1`, `per_device_train_batch_size=2`, gradient accumulation 8, learning rate `2e-4`, and `max_seq_length=512`. The log says "Time elapsed: 4h 57m 36s" and "Train loss:   0.8180." LoRA rank is 16 and alpha is 32. The base was loaded "in 4-bit QLoRA mode" with NF4 and double quantization. The notebook then says "Merging LoRA adapter into base model" and "Merged model saved! Total size: 13.50 GB." The Hub file list is three float16 weight shards and no `adapter_config.json`. An earlier cell in the same notebook sets 3 epochs, batch size 1, and sequence length 1024; a later cell overwrites those to the values that match the completed run. The card's line "QLoRA enables full fine-tuning of 7B models on 2× Tesla T4 GPUs" describes that QLoRA run, not a full-parameter update. The card says frozen parameters are 3.758B and 1.1% were trained. The same notebook cell prints "Frozen parameters:    3.758B" and then the PEFT summary "trainable params: 41,943,040 || all params: 7,289,966,592 || trainable%: 0.5754." The Hub API reports 7,248,023,552 float16 parameters in the uploaded files. The card's research question calls it "a 7B parameter LLM."

The parent is `mistralai/Mistral-7B-Instruct-v0.3`. The card names that id. `config.json` has `"_name_or_path": "mistralai/Mistral-7B-Instruct-v0.3"`. The notebook printed "Model:        mistralai/Mistral-7B-Instruct-v0.3." No paper or GitHub repository outside this Hub repo names this checkpoint. The card says "Research Paper: In Progress." The three cited papers are LoRA, QLoRA, and Mistral 7B.

The card presents a chatbot that gives mental-health support, and the warning is a disclaimer. The usage example says, "You are a compassionate, empathetic mental health support assistant. You listen carefully, validate feelings, and provide thoughtful, evidence-based guidance." The purpose list says the assistant should validate feelings, give coping strategies, offer psychoeducation, and encourage professional help. The warning says, "This model is NOT a replacement for professional therapy or crisis intervention," and "This model is intended for research purposes only." It still describes the model as "Designed for support and psychoeducation, not diagnosis or treatment." The card's front matter says `language: en` and `license: apache-2.0`.

Serving uses the Mistral instruct chat template stored in `tokenizer_config.json`. That template does not contain a fixed mental-health system prompt (`use_default_system_prompt` is false). `generation_config.json` does not set temperature or top-p. The card's example uses temperature 0.7, top_p 0.9, max_new_tokens 300, repetition_penalty 1.4, do_sample true, and no_repeat_ngram_size 4. `config.json` sets `max_position_embeddings` to 32768. Training truncated at 512 tokens. The notebook's CounselChat formatter used a longer system prompt than the card's example, including "you offer genuine emotional support, psychoeducation, and coping strategies." The notebook file contains a hard-coded Hub token. This record does not copy it.
