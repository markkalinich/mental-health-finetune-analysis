## Record

The training set is MedInstruct. The card says it is "combined from BioInstruct and AlpaCare-MedInstruct-52k." The thesis repo stores that combination as `medical_train.jsonl`, 53,370 rows, plus 2,965 validation rows. BioInstruct's card says it is "25k instructions and demonstrations generated by OpenAI's GPT-4." AlpaCare-MedInstruct-52k has 52,002 training rows. Its card does not say who wrote them. There is no Hub dataset id named MedInstruct.

Training is full instruction tuning. The notebook says "full fine-tuning trains all model parameters" and sets every parameter's `requires_grad` to true. It loads `meta-llama/Llama-3.2-3B-Instruct` in bfloat16, trains for 3 epochs at learning rate `2e-5`, with `per_device_train_batch_size` 8 and gradient accumulation 4. The loss is on the assistant reply only. The card also says "Framework: PEFT 0.18.1." This notebook uses `Trainer` and does not import PEFT. It does not print this Hub repository id. It saves the weights under the local name `medical_llama3_full_model`.

The card and the notebook name the same parent, `meta-llama/Llama-3.2-3B-Instruct`. The card's title says 3B. The Hub file list reports 3,212,749,824 parameters.

The use claim is weak. The card says the model was tuned "to improve medical quantitative reasoning." The GitHub README says this is a master's thesis at UCOL, investigating whether smaller models could improve at that task. The card states no medical warning. The license is `llama3.2`.

The audience is the thesis author and other researchers. The card does not name a function from the study list, such as diagnosis or triage. It does not name a medical specialty. The clinical work it states is medical quantitative reasoning. The thesis evaluates the variants on MedCalc-Bench, MedQA-USMLE, and a MedInstruct test set. A result file for the local full medical checkpoint reports MedQA 4-options accuracy 0.425 on 1,273 samples. Those benchmarks are evaluation only.

Serving is text. The training system prompt is an empty string. `generation_config.json` sets `do_sample` true, temperature 0.6, and top_p 0.9. `config.json` sets the context length to 131072. Training truncated sequences at 2048 tokens. A chat template file is present.
