## Record

The training set is VQA-RAD, `flaviagiammarino/vqa-rad`. The dataset page loads. It says the questions "were manually generated by a team of clinicians," in English, from MedPix radiology images. After dropping four duplicate triplets the page has 2,244 pairs: 1,793 train and 451 test. The model card says "2,248 question-answer pairs across 315 radiology images" and evaluates on the "official test split (451 samples)."

Training was QLoRA and the trainer is named SFT. The card says "QLoRA (4-bit quantized base, LoRA adapters)" and "Framework: Unsloth + TRL SFTTrainer." Rank 16, alpha 32, dropout 0.05. The vision encoder was frozen. "The LoRA adapter weights have been merged into the base model" and "merge_and_unload() applied post-training." Three epochs, learning rate 2e-4, per-device batch 1, gradient accumulation 4, effective batch 4. The line "trained 2x faster with Unsloth" is the library badge and is not the evidence for the method. The upload is four full weight shards, 3,754,622,976 F16 parameters, and there is no `adapter_config.json`. The Hub API still marks it as a PEFT adapter.

The YAML and the details table say the parent is `Qwen/Qwen2.5-VL-3B-Instruct`. The footer says "Finetuned from model : unsloth/Qwen2.5-VL-3B-Instruct." The card says "At 3B parameters." Language is English. License is Apache 2.0.

The stated use is "Medical radiology question answering (academic and educational contexts)." That is a moderate claim: academic image questions, not diagnosis for a patient. The prohibition is explicit: "It should not be used for clinical decision-making or patient care."

It is for "medical and life science students" and for "Prototype development for medical education tools." It answers questions about a radiology image, and the suitable-use list also says "Generating explanations of radiological findings and imaging concepts." The example asks "Is there any abnormality in this chest X-ray?" and tells the model to answer in 1–5 words. The task is radiology visual question answering. The specialty is radiology. On 451 test items, exact match is 53.88% and token F1 is 58.43%. Closed-ended exact match is 77.29%. Open-ended exact match is 24.50%.

The example opens an image and a question together, so the input is not text only. The chat template injects "You are a helpful assistant." Context length is 128000. `generation_config.json` sets temperature 1e-6, `do_sample` true, and repetition penalty 1.05. The example uses `max_new_tokens=32`.

No paper and no GitHub repo name this checkpoint. QLoRA and VQA-RAD match the inventory. The inventory parent matches the YAML. The footer names `unsloth/Qwen2.5-VL-3B-Instruct` instead.
