## Record

The training set is VQA-RAD, Hub id `flaviagiammarino/vqa-rad`. The card says "Data: VQA-RAD (radiology VQA, CC0)". The dataset loads. After the card drops four duplicate triplets, it has 2,244 question-answer pairs: 1,793 train and 451 test. The dataset card says "The question-answer pairs were manually generated by a team of clinicians," so the provenance is human. The language is English.

The card says "Method: LoRA fine-tune (PyTorch + PEFT, trained locally on Apple Silicon / MPS)". That is LoRA, not a named loss. No epoch, step count, learning rate, batch size, or LoRA rank is stated. The published repository has `model.safetensors` (256,484,928 float32 parameters) and no `adapter_config.json`. The card points to `finetune/BENCHMARK.md`, and that file is not in this repository. No GitHub repository and no paper name this checkpoint.

The parent on the card is "Base: HuggingFaceTB/SmolVLM-256M-Instruct". No source outside the card states that parent.

The use claim is strong. The card offers "Decision support" and "wound-care & medical VQA". The warning is a disclaimer: "Decision support, not a diagnosis. A trained health worker stays in the loop." It does not say the model must not be used.

A purpose is stated: "offline, private wound-care & medical VQA for disconnected clinics in Morocco." The audiences are a trained health worker and "disconnected clinics in Morocco." The functions are interpreting a medical image ("Assess this wound.") and supporting a clinical decision. The usage code prints a decoded generation, so the output kind is a chat reply. The card does not show a sample answer.

The clinical task is wound-care visual question answering, which is not one of the named task labels, so it is recorded as other. The training and test data are radiology images. The specialty words on the card are wound care and radiology. On the VQA-RAD test split the card reports closed-ended accuracy 0.439 and open-ended token-F1 0.228.

Serving is not text-only. The example opens `wound.jpg` and passes it with the question. The architecture is `Idefics3ForConditionalGeneration`. Text context length is 8,192. The example sets max_new_tokens to 128. generation_config.json does not set temperature or top-p. The chat template has no system sentence. The license is apache-2.0. The inventory row (LoRA, VQA-RAD, SmolVLM-256M-Instruct) matches the card.
