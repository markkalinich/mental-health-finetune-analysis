## Record

The training set is Med-MathInstruct. The card says it is MedInstruct, "combined from BioInstruct and AlpaCare-MedInstruct-52k, plus MQR data from MedCalc-Bench-v1.0," and the description says that added portion is 15%. The train file has 61,375 rows and the validation file has 3,409. The MedInstruct-only train file has 53,370 rows, so this file has 8,005 more rows. BioInstruct's card says the instructions were generated by GPT-4. AlpaCare's card does not say who wrote its 52,002 rows. `ncbi/MedCalc-Bench` is a public dataset of 10,543 training patient-note calculations. The thesis sample file labels calculation rows `Subset: MedCalc_Bench`. There is no Hub id named Med-MathInstruct.

Training is full instruction tuning. The notebook says "full fine-tuning trains all model parameters" and sets every parameter's `requires_grad` to true. It loads `meta-llama/Llama-3.2-3B-Instruct` in bfloat16, for 3 epochs, learning rate `2e-5`, batch size 8, and gradient accumulation 4. The card also says "Framework: PEFT 0.18.1." This notebook uses `Trainer` and does not import PEFT. It saves the weights as `medical-math_llama3_full_model` and does not print this Hub id.

The card and the notebook name the same parent. The title says 3B. The Hub file list reports 3,212,749,824 parameters.

The use claim is weak. The card says the model was tuned "to improve medical quantitative reasoning." The GitHub README says this is a master's thesis at UCOL. The card states no medical warning. The license is `llama3.2`.

The audience is researchers. The card does not name a listed function such as diagnosis or triage. It does not name a specialty. The work it states is medical quantitative reasoning, and the added rows ask for a clinical calculation with step-by-step reasoning and a final number. MedQA and MedCalc in the thesis are evaluation. A result file for the local math full checkpoint reports MedQA 4-options accuracy 0.416 on 1,273 samples. The README says the added calculation data improved MedCalc-Bench and had little effect on the other benchmarks, without a score for this file alone.

Serving is text. The training system prompt is empty. `generation_config.json` sets `do_sample` true, temperature 0.6, and top_p 0.9. `config.json` sets the context length to 131072. A chat template file is present.
